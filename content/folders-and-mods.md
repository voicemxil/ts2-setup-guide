# Folders & Mods

## Where the game lives

**Game files** (the install folder):

::: track UC
`C:\Program Files (x86)\Origin Games\The Sims 2 Ultimate Collection` (newer installs may say `EA Games` instead of `Origin Games`).

Each pack has its own folder with a `TSData` directory. The last pack — `Fun with Pets\SP9` — is the one the game actually runs from: `TSBin` holds the executables, and `TSData\Res\Config` holds `Graphics Rules.sgr`.

**Disc installs** are laid out differently: every pack gets its own folder named in full (e.g. `The Sims 2 Mansion and Garden Stuff` instead of `Fun with Pets\SP9`), and the game runs from the *newest pack you own* — Mansion & Garden's `TSBin` if you have it. Wherever this guide says `Fun with Pets\SP9`, disc users should read "your newest pack's folder."
:::

::: track Legacy
`C:\Program Files (x86)\Steam\steamapps\common\The Sims 2 Legacy Collection` (Steam) or the EA App's install library. Packs live in flat folders at the root (`Base`, `EP1`–`EP9`, `SP1`–`SP7` — Mansion & Garden is `EP9`), and the game runs from `EP9`: executables in `TSBin`, `Graphics Rules.sgr` in `TSData\Res\Config`.
:::

**Save files** (Documents) — created on first launch:

::: track UC
`Documents\EA Games\The Sims 2 Ultimate Collection\`
:::

::: track Legacy
`Documents\EA Games\The Sims 2 Legacy\`
:::

Inside the Documents folder:

- `Neighborhoods\` — your actual saves. In TS2, the neighborhood **is** the save.
- `Downloads\` — where `.package` mods and custom content go (create it if it doesn't exist)
- `Config\` — `UserStartup.cheat` and other user config
- `Logs\` — crash/exception logs; `(computer name)-config-log.txt` is the first thing to check when troubleshooting

## Installing custom content & mods

Most CC and mods are `.package` files: extract them into the `Downloads` folder above. That's it.

- Some mods (lighting mods, default replacements with special instructions) install into the game folders instead — creators include instructions, **read them before downloading**
- `.asi` mods are loaded by Sims2RPC (UC) or TS2 Extender (Legacy) from their respective mod folders, not from Downloads
- Video: [How to Install Custom Content & Mods](https://www.youtube.com/watch?v=u9r4ch5m4mc) by Pleasant Sims
